Read this first  The material you are looking for is not on our servers. We host no video, no files and no catalogue. We cannot delete something we never had, and we are not the party to send a takedown to. The action belongs with the host that actually serves the bytes — this page tells you how to find them.

2. Where the content actually lives — and who to contact

If a title you own is being distributed, the file sits on somebody else's infrastructure. Trace it, then contact that party. This takes a few minutes and is the only route that actually removes something:

StepWhat to do
1. Find the host Resolve the domain that serves the stream: dig +short example.site, whois example.site, or any whois lookup site. The hosting provider named in the whois record (or the CDN in front of it) is who you are after — not the domain owner alone.
2. If a CDN is in front Cloudflare, Fastly, Akamai and similar publish their own abuse forms. The domain's DNS or the response headers (server:, cf-ray:) tell you which one.
3. Send the notice there Hosts act on their own abuse address or DMCA form, and they can suspend the account. Include the exact URL, the work, and proof you hold the rights.
4. If it is on GitHub Anything inside this repository or its release files is GitHub's to act on: github.com/contact/dmca. GitHub notifies the account holder, and we comply with what they decide.
5. If it is on our app Our app is only a player. A complaint about the software itself (for example its icon or repository files) goes to GitHub in step 4 as well — we have no separate takedown desk.

3. What we will not do

  • We will not remove, alter or "hold" content we do not host — we have no copy of it to remove.
  • We will not act as an enforcement agent for third parties: no forwarding, no investigating claims, no disclosing anything about the people who use the app.
  • We will not answer takedown mail, because there is no mail addressed to this project for that purpose. The only contact surface is the repository.

4. What the source code is, legally speaking

The app is source code under the MIT licence, published at github.com/1HP2DIE/Dr-Animo. It contains no expression of yours: no frames, no audio, no subtitle text, no artwork from any series. It is a video player and an HTTP client — the same category of software as a browser or VLC.

Endpoints are runtime configuration, not bundled content. A build with no endpoint configured shows an empty catalogue and cannot resolve anything.

5. What we do if we are told about a specific source

VoluntaryIf a rights holder points us at a specific endpoint and the claim looks straightforward, that endpoint can be dropped from the shipped configuration — no rebuild of the app's logic, just configuration. This is a courtesy, not a legal duty: we are not a service provider under 17 U.S.C. § 512 and we do not claim that safe harbour. Withdrawn buildsIf GitHub removes a release after their own process, the download mirror on this site is pulled with it. No removed build is offered for download. Repeat sourcesSources tied to repeated valid complaints are not re-added. No data to preserveWe hold no logs of what anyone watched, so there is nothing to preserve, disclose or delete.

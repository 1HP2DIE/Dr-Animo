What is the Dr Animo APK?

Dr Animo is a native Android anime client shipped as a single APK. Unlike browser-wrapped apps, it never spins up a WebView for playback: the catalogue is read from a local Room database and streams are played by Media3/ExoPlayer, with the Referer and X-Requested-With headers rebuilt on every playlist, variant and segment request. That is what makes scrubbing, subtitles and resume-position behave like a real video player instead of a web page.

The app is built with Kotlin 2.0, Jetpack Compose and AGP 8.7, targets API 35, and runs from Android 7.0 up. It is published only here and on GitHub — there is no Play Store listing, no telemetry SDK, and no advertising ID in the manifest.

Features

Native HLS playback

Media3/ExoPlayer with a custom OkHttp data source; referer and UA are attached to the playlist, every variant and every segment.

Offline-first catalogue

Room is the source of truth. Cold start renders instantly with zero network, and search is a local FTS4 index.

No WebView renderer

Playback never depends on Chromium. A WebView is used only to clear a challenge on hosts that demand one, then the request is replayed.

Resume and subtitles

Position, speed and sleep timer persist per episode; subtitle matching is token-based and tolerant of release naming.

Two catalogue sources

A primary API plus a scraped second source with its own PD2 stream resolution, both behind a shared transport router.

Open source

MIT licensed, 400+ files of Kotlin, unit tests for the resolver and parsers. Read it, fork it, audit it.

Frequently asked questions

What is Dr Animo APK?

A native Android anime client distributed as an APK: offline-first catalogue in Room, native HLS playback through Media3/ExoPlayer, no WebView renderer.

Is the Dr Animo APK free?

Yes. The APK is free and the full source is public under MIT at 1HP2DIE/Dr-Animo.

Which Android versions are supported?

Android 7.0 (API 24) and newer; the manifest targets API 35.

How do I update Dr Animo?

Download the newer APK from Releases and install it over the existing app — the signature matches, so your data is kept.

Does it work offline?

Browsing and search work offline because the catalogue is local. Playback needs a connection; streams are not cached.

Is it on the Play Store?

No. APK-only distribution from GitHub releases.

Why "under the black hole"?

It is the app's tagline: nothing else surfaces there, only Dr Animo. The only indexable page is this one and the repository.
